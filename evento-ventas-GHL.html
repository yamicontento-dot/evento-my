⚡ Conectar Firebase (tiempo real)
Para sincronizar Milena y Yamile en tiempo real necesitas un proyecto Firebase gratuito. Solo se hace una vez desde cualquier computador o celular.
1Crear proyecto Firebase
Ve a console.firebase.google.com → "Agregar proyecto" → nombre: evento-my → desactivar Analytics → Crear
2Crear base de datos Firestore
Menú izquierdo → Firestore Database → "Crear base de datos" → modo Producción → elegir región (us-east1) → Listo
3Abrir Reglas y pegar esto → Publicar
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /{document=**} { allow read, write: if true; } } }
4Obtener datos de configuración
Ícono ⚙️ → Configuración del proyecto → "Tus apps" → botón </> → registrar app → copiar valores del firebaseConfig
Pega aquí los valores:
apiKey *
projectId *
appId *
